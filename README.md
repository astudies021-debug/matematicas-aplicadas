# Matemáticas Aplicadas

Espacio de estudio con enfoque en comprensión profunda, modelado y rigor.

## Estructura
| Carpeta | Contenido |
|---|---|
| `apuntes/` | Teoría por tema: intuición → fundamentos → formalismo → aplicaciones |
| `ejercicios/` | Problemas resueltos con intento propio y corrección |
| `referencias/` | Libros, artículos y recursos |

## Plantilla para ejercicios
1. **Enunciado**
2. **Modelo e hipótesis** (¿qué se supone y por qué?)
3. **Análisis dimensional / comprobación de unidades**
4. **Mi intento**
5. **Corrección y errores detectados**
6. **Lección aprendida**
